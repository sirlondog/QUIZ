# QUIZ

Квиз-блок для сайта в стиле Marquiz.

## Структура

- `index.html` — разметка блока
- `style.css` — стили
- `script.js` — логика выбора вариантов

## Текущий статус

- Шаг 1: «Как будем подбирать?» с двумя вариантами ответа:
  - Подберите под мой бюджет
  - Самостоятельно

## Запуск

Открыть `index.html` в браузере.
